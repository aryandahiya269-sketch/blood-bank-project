Blood Bank Donor & Blood Inventory System (Frontend)
=====================================================
How to run: double-click index.html (opens in any browser). No installation needed.

Files:
  index.html     - page structure (HTML)
  css/style.css  - all styling and animations
  js/script.js   - donor registration, blood request, search/filter, animations

Features:
  - Live blood inventory with status (Available / Low / Critical)
  - Blood group compatibility checker
  - Donor registration with validation
  - Blood request (stock is deducted automatically)
  - Donor directory with search and filter
  - Donation camps, how it works, FAQ

Note: Data is stored in browser memory only, so it resets on page refresh.
Before submitting, change the college name, your name and contact details in the footer.
